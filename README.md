## 🚀 Quick Start Guide

### 1. Installation & Running Locally
```bash
# Navigate to project folder
cd Thakana

# Install required dependencies
npm install

# Start the live backend server
npm start
```

The system will start on **`http://localhost:5000`**.

## 🔄 The 6-Step Supply Onboarding Lifecycle

1. **Hostel Owner Registration:** Owner creates an account with Name, Phone, CNIC, and Address.
2. **Add Your Hostel:** Submits hostel rent, deposit, room/bed capacity, gender policy, campus proximity, photos, and active amenities.
3. **Inspection Request:** Status is set to **`🟡 Pending Inspection`** (automatically hidden from student search).
4. **Field Inspector Visit:** Thikana team conducts on-site sensory testing (Water TDS &lt;140 PPM, Study Noise &lt;40 dB, CCTV count, warden verification). Status becomes **`🔵 Inspected`**.
5. **Admin Approval:** Founders review the audit dossier and sign off with one-click approval.
6. **Public Marketplace Listing:** Status becomes **`🟢 Approved`** and immediately appears in student searches with verified badge!
